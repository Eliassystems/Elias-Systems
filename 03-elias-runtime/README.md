# Elias Runtime — Constitutional Control Plane

## Elias Systems — Governance Between Intelligence and Consequence

The Elias Runtime is the layer where governed reasoning becomes system-level control.

HPM asks:

**What is the system epistemically entitled to say?**

The Elias Runtime asks the next question:

**What is the system constitutionally permitted to do with that determination?**

The Runtime is not an AI model.

It is a constitutional control plane designed to govern the movement from intelligence and capability toward consequence.

---

## Architectural Position

The public Elias sequence is:

**Human → Identity → Purpose → Constitutional Principles → Epistemic Governance → Constitutional Control → Execution → Witness**

The preceding HPM layer governs claim standing, evidence, uncertainty and controlled release.

The Runtime governs how downstream capability operates inside constitutional limits.

---

## Core Principle

**CAPABILITY ≠ AUTHORITY**

A model, agent or system may be technically capable of acting without possessing present authority to execute.

The Runtime therefore separates:

**INTELLIGENCE ≠ AUTHORITY**

**DETERMINATION ≠ EXECUTION**

**PERMISSION ≠ CAPABILITY**

**VALID THEN ≠ VALID NOW**

Execution must remain subordinate to current governing standing.

---

## Constitutional Ordering

The Runtime preserves the principle that intelligence operates inside governance rather than governance being added afterwards.

The governing direction is:

**Identity defines Purpose.**

**Purpose defines Constitutional Principles.**

**Constitutional Principles govern Intelligence.**

**Intelligence enables Capability.**

**Capability does not create its own Authority.**

**Witness preserves Accountability.**

---

## Runtime Governance

The Runtime is intended to govern system behaviour through explicit constitutional states rather than allowing model output to become consequence automatically.

The public architecture recognises states including:

- ADMISSIBLE
- RECOVERY
- DEGRADED
- UNKNOWN
- DENIED

Uncertainty must not be silently converted into permission.

Denial must not be cosmetically rewritten into execution.

---

## Governance Before Execution

The Runtime places governance before consequential execution.

A candidate action may therefore be:

- permitted;
- constrained;
- deferred;
- denied;
- escalated;
- or redirected through recovery.

Intelligence remains a capability operating inside the constraint envelope established by governance.

It does not possess independent constitutional authority.
