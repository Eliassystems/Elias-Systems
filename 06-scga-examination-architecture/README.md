# SCGA Examination Architecture v0.6 — Examine the Examiner

## Elias Systems — A Public Starting Point for Testing the Test

AI governance cannot become credible merely by creating more tests.

The examination itself must also be capable of being challenged.

The SCGA Examination Architecture was developed to answer a different question:

**Has the examination earned the right to support its conclusion?**

This layer turns the discipline back onto the machinery used to inspect governed systems.

---

## Architectural Position

The public Elias journey has moved through:

**Human → Identity → Epistemic Governance → Constitutional Control → Authority Revalidation → Consequence-Bearing Execution → Examination**

The preceding layers ask whether intelligence and execution remain governed.

This layer asks whether the evidence and examination used to judge those systems are themselves sufficiently disciplined.

---

## Core Examination Sequence

The examination architecture follows the sequence:

**OBJECT → CLAIMS → EVIDENCE → CRITERIA → FALSIFIERS → GATES → DISPOSITION**

The object must be identified before examination.

The claims must be bounded before results are known.

Evidence must remain attributable.

Positive criteria must be defined prospectively.

Falsifiers must be capable of producing failure.

The examination boundary must not be rewritten afterwards to obtain a preferred result.

---

## Positive Evidence Is Not Absence of Failure

A central rule is:

**FALSIFIER NOT OBSERVED ≠ CLAIM ESTABLISHED**

Surviving an attack can support survival of that attack within the frozen scope.

It does not automatically establish universal correctness.

Positive conclusions require their own positive establishment criteria.

---

## Causal Examination

A system that refuses everything can appear safe under negative testing.

A broken actuator can appear governed because nothing happens.

The examination must therefore distinguish:

**GOVERNANCE ≠ INABILITY**

Where prevention is being claimed, relevant negative cases should be paired with valid-state causal controls showing that the same governed route can operate when the required conditions are satisfied.

---

## Boundary and Topology

A perfect governance gate does not establish a governed system if an in-scope execution route exists around it.

The examination architecture therefore treats complete mediation and boundary non-bypassability as separate examination questions.

At the same time, it does not pretend to prove unknowable universal topology.

Positive conclusions remain bounded to the frozen topology and execution scope actually examined.

---

## Evidence Ceiling

The examination must never award a stronger conclusion than its evidence can support.

**EVIDENCE SURFACE ≠ UNIVERSAL REALITY**

**OBSERVED SCOPE ≠ ALL POSSIBLE SCOPE**

**SUPPORTED WITHIN FROZEN SCOPE ≠ UNIVERSALLY PROVEN**

Unknown or unavailable evidence remains unknown or unavailable.

It must not be silently reconstructed from architectural assumption.

## Frozen Stopping Rule

Before the later successor reviews, a stopping rule was frozen so that the redesign process could not move its own goalposts after seeing the result.

The rule required all four conditions:

**SR-1 — BLOCKING_FINDINGS = 0**

**SR-2 — NEW_PRIMITIVE_FAILURE_CLASS = 0**

**SR-3 — any remaining findings are bounded limitations or hardening matters that cannot create a materially false strongest-positive result**

**SR-4 — no remaining pathway can promote an unsupported, unestablished, insufficient, divergent, invalid or out-of-model state into the strongest positive disposition**

The rule also states:

**A transparent bounded assumption is not a hidden proof.**

---

## v0.6

SCGA Examination Architecture v0.6 became the frozen successor at which the precommitted redesign stopping condition was satisfied within the bounded review scope.

The significant point is not that criticism became impossible.

The significant point is that the remaining review no longer demonstrated a pathway by which the examination architecture could award materially more than its frozen evidence, assumptions and scope legitimately earned.

That is the stopping condition.

Not perfection.

Bounded examinability.

## Anti-Goalpost Rule

The stopping threshold cannot be changed retrospectively because a later result is inconvenient.

Any successor stopping rule must itself:

- have a distinct identity;
- be justified by a materially new reason;
- be frozen before the successor it governs;
- and have no retrospective effect on an already completed review.

---

## What This Architecture Is Not

This is not:

- a universal Elias test;
- a certification regime;
- proof that every governed system is safe;
- proof that SCGA itself is universally correct;
- regulatory approval;
- legal authority;
- or a claim that one examination architecture should control every other sovereign architecture.

It is a public examination architecture intended to be challenged.
