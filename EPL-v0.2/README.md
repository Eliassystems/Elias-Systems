# Elias Emotional Programming Layer — EPL v0.2

**Status:** `ESTABLISHED_WITHIN_BOUNDED_SCOPE`

EPL v0.2 is a standalone computational governance layer for representing, interpreting, governing and calibrating emotionally relevant information while preserving epistemic boundaries.

Its purpose is not to claim that software possesses human emotion.

Its purpose is to prevent emotionally relevant information from being silently converted into stronger claims, authority or consequential action than the evidence supports.

## Core separations

EPL v0.2 preserves distinctions including:

- signal ≠ interpretation
- observation ≠ inference
- direct report ≠ machine interpretation
- reported feeling ≠ inferred emotional state
- emotional context ≠ fact
- interpretation ≠ authority
- pattern ≠ diagnosis
- support ≠ agreement
- care ≠ compliance
- uncertainty ≠ failure
- capability ≠ authority

EPL v0.2 does **not** establish:

- perfect emotional intelligence
- consciousness
- genuine human emotion
- therapy
- clinical psychology
- clinical diagnosis
- mind reading
- moral perfection
